# Definition of Done

A product backlog item is done only when:

- acceptance criteria pass;
- tests cover its main path and important failure path;
- CI is green;
- data migrations and API changes are documented;
- no secret or copyrighted/unverified dataset is committed;
- the owner has reviewed the change through a pull request;
- Nurdos has run the demo/GWT check;
- for AI changes, Alimzhan has recorded the dataset version, threshold and metrics.
