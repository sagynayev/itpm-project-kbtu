# Evaluation set

`questions.csv` содержит 28 in-scope и 2 out-of-scope вопроса для первичного retrieval test.

Порядок работы:

1. Запустить каждый вопрос через API.
2. Два участника независимо отмечают `retrieved_relevant` и `answer_safe`.
3. Разногласия разрешает третий участник или приглашённый инструктор.
4. Зафиксировать snapshot commit, threshold и дату официальной базы.
5. Для TSIS O2 использовать минимум 30 вопросов; для O3 расширить набор минимум до 100 размеченных ответов.

Не заполнять expected point «по памяти»: открыть ссылку «Әділет» и записать точный пункт после проверки.

## Baseline — 15 November 2026

Команда `evaluate_retrieval` получила **30/30 по маршрутизации в правильную главу** на этом наборе и snapshot редакции 3 November 2026. Это smoke test intent routing, а не доказательство юридической корректности ответа. Для O2/O3 всё ещё нужны точные labels пунктов, ручная проверка и минимум 100 ответов.
